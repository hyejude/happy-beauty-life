# 행코위

화장대에 가진 제품과 위시 리스트, 화장품 소비, 코덕 일정을 한곳에서 관리하는 웹 앱입니다.

## 주요 기능

- 내 화장대 제품 등록, 수정, 검색, 카테고리 및 개봉 상태 관리
- 제품 즐겨찾기와 이번 주 신상 확인
- 위시 리스트와 구매 우선순위 관리
- 소비 내역 기록 및 월별 소비 확인
- 캘린더와 코덕 플래너 일정 관리
- 립·블러셔 섞발 조합 추천
- 데이터 백업 및 복구
- 낮/밤 화면 모드

## 실행 방법

별도 설치나 빌드 과정 없이 `index.html`을 브라우저에서 열면 됩니다. Tailwind CSS와 아이콘은 CDN을 사용하므로 처음 열 때 인터넷 연결이 필요합니다.

## 파일 안내

- `index.html`: 웹 앱 화면
- `app.js`: 화면 동작과 데이터 관리
- `styles.css`: 공통 스타일 및 낮/밤 모드
- `preview.html`: 앱과 별도로 열 수 있는 정적 화면 미리보기

## 데이터 저장

제품, 위시, 소비 기록 등은 현재 브라우저의 `localStorage`에 저장됩니다. 같은 브라우저에서는 새로고침해도 유지되지만, 다른 기기나 브라우저와 자동으로 동기화되지는 않습니다. 앱의 데이터 백업 기능으로 별도 백업을 보관할 수 있습니다.

## GitHub Pages로 공개하기

1. GitHub에 저장소를 만들고 이 폴더의 파일을 올립니다.
2. 저장소의 **Settings → Pages**에서 배포 소스를 설정합니다.
3. 배포가 끝나면 GitHub Pages가 제공하는 주소로 앱에 접속할 수 있습니다.

배포해도 앱 데이터는 방문한 사람의 브라우저에 각각 저장됩니다. 사용자 간 데이터 공유나 계정 동기화에는 별도의 서버가 필요합니다.
